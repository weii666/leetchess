# Product Overview

leetchess 是**象棋排局解題網站,形態類似 leetcode**:一個經過驗證的題庫,使用者逐題挑戰,自行追蹤練到哪裡。

每一題是一個「紅先必勝」的古譜排局。使用者執紅,引擎執黑當陪練,要在實戰中把它贏下來。交付形態是 service —— 開頁面就能練,不安裝。

## Core Capabilities

- **題庫瀏覽** — 依難度、標籤、出處書目篩選;列表以題號與局名為主要識別,一眼可掃
- **單題對局** — 執紅走子,引擎即時計算黑方應手;合法著法由引擎提供,前端不判規則
- **真終局停局** — 一路下到分出勝負(輪方無合法著法),不提早介入、不強迫重來
- **三態諮詢信號** — 顯示目前殺勢:紅方即將取勝 / 黑方即將取勝 / 未搜得殺著。**僅供參考,不決定停局**,允許誠實地說「未知」
- **完成標記** — 每題一個 on/off 圖示,**由使用者自行標記**,存於瀏覽器本機

## Target Use Cases

象棋愛好者練習古譜排局的殺法技術。

訓練目標是**泛化而非背譜**。黑方每次都走在「抵抗最頑強的一檔」,並在該檔之內變化 —— 使用者必須面對各種最強抵抗都能贏下來,而不是記住一條固定路線。變化只允許發生在最頑強應手之間,絕不走出較弱的手,那等於放水、殺法變簡單、訓練失真。

## Value Proposition

- **題目經現代引擎驗證** — 古譜排局有相當比例的「紅勝」結論已被現代引擎推翻(實際為和局甚至紅負)。本產品在收題階段就剔除或改標註,不讓使用者照譜走卻贏不了
- **黑方不放水** — 應手取自引擎最頑強一檔,品質有下限保證
- **零安裝、零下載** — 引擎在伺服器端,使用者端不需要取得任何引擎構件

## Non-Goals

明確排除,不需重新討論:

- **帳號、雲端同步、社群功能** — 完成狀態只在本機,換裝置即歸零,這是刻意的取捨
- **離線可用** — 引擎在伺服器端,每一手需要網路往返
- **自動判定解題成功** — 系統不偵測使用者是否「解出」,完成與否由使用者自行標記。對局結果與完成標記是兩件事
- **商業化** — NNUE 授權禁止未經許可的商業使用,詳見 `tech.md` 的授權約束

## 產品邊界的兩個易混淆處

1. **三態信號不是判決。** 它會抖、未知偏多是預期行為。停局只認真終局,所以信號報錯的代價只是一次顯示抖動,不會誤判勝負。
2. **走脫判定表尚未實作。** 「就是這一步」的移動級確定回饋是已規劃但延後的能力,目前不存在。使用者走脫後不會被攔下,對局照樣繼續到分出勝負。
